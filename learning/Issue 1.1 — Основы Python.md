# Issue 1.1 — Основы Python

## 1. Что такое Python

### 1.1. Определение

**Python** — это высокоуровневый язык программирования общего назначения.

Разберём определение на составляющие.

**Язык программирования** — формальный язык, с помощью которого человек записывает инструкции для компьютера. Эти инструкции описывают, какие действия должна выполнить программа: посчитать сумму, сохранить информацию, обработать текст, обратиться к базе данных или отправить сообщение.

Например:

```python
print("Hello, Family Budget Bot!")
```

Эта инструкция говорит Python вывести на экран текст `Hello, Family Budget Bot!`.

**Высокоуровневый язык** — язык, синтаксис и конструкции которого относительно близки к человеческому способу мышления и скрывают многие низкоуровневые детали работы компьютера.

Процессор непосредственно выполняет машинные инструкции, а не команды Python. Поэтому между программой на Python и процессором существует программный слой, который обеспечивает выполнение написанного кода.

Для сравнения:

```python
total = 100 + 200
print(total)
```

В Python достаточно написать понятное выражение сложения. Не нужно самостоятельно управлять регистрами процессора или вручную записывать машинные инструкции.

**Язык общего назначения** — язык, который не ограничен одной конкретной областью применения.

Python используют для:

- **Веб-разработки:** создание серверной части сайтов и веб-приложений.
- **Автоматизации:** выполнение повторяющихся действий, обработка файлов, работа с документами.
- **Telegram-ботов:** создание ботов для общения с пользователями и выполнения различных задач.
- **Анализа данных:** обработка таблиц, статистики и больших наборов информации.
- **Машинного обучения:** создание моделей, работающих с данными и выявляющих закономерности.
- **Тестирования:** автоматическая проверка программного обеспечения.
- **Разработки инструментов:** создание небольших утилит и полноценных приложений.

В нашем проекте Python будет использоваться для создания Telegram-бота, который позволит двум участникам семьи вести общий учёт расходов.

### 1.2. Почему Python популярен

У Python есть несколько особенностей, благодаря которым он широко применяется:

1. **Понятный синтаксис.** Код обычно легче читать, чем код на многих более низкоуровневых языках.
2. **Большая стандартная библиотека.** Вместе с Python поставляется набор готовых инструментов для работы с файлами, датами, математикой, сетью и другими задачами.
3. **Большая экосистема библиотек.** Разработчики могут подключать готовые решения для Telegram, баз данных, веб-разработки, тестирования и других областей.
4. **Кроссплатформенность.** Python доступен для Windows, macOS и Linux.
5. **Большое сообщество.** Существует много документации, учебных материалов и примеров решения распространённых задач.

### 1.3. Как выглядит программа на Python

Простейший пример:

```python
print("Hello, Family Budget Bot!")
```

Здесь:

- `print` — встроенная функция Python для вывода информации.
- Круглые скобки `()` содержат аргумент функции.
- `"Hello, Family Budget Bot!"` — строка текста.
- Кавычки обозначают начало и конец строкового значения.

Ещё один пример:

```python
total = 100 + 200
print(total)
```

Здесь:

- `total` — имя переменной.
- `=` — оператор присваивания.
- `100 + 200` — выражение, результатом которого будет `300`.
- `print(total)` выводит значение переменной.

Результат выполнения:

```text
300
```

### 1.4. Важное понимание

Python — не программа для написания кода и не редактор текста. Это язык программирования.

Для работы с ним используются разные инструменты:

- **Python** — язык, на котором пишется программа.
- **Python Interpreter** — программный механизм, обеспечивающий выполнение Python-кода.
- **IDE или редактор кода** — инструмент, в котором удобно писать и редактировать программы. Например, Visual Studio Code.

Эти понятия связаны, но не являются одним и тем же.

## 2. Чем интерпретируемый язык отличается от компилируемого

### 2.1. Как компьютер выполняет программу

Программист обычно пишет код на языке, который удобно читать и понимать человеку.

Но процессор компьютера выполняет машинные инструкции — команды, представленные в форме, понятной конкретной архитектуре процессора.

Поэтому исходный код необходимо обработать и подготовить к выполнению.

Существуют разные подходы к этому процессу. Два основных понятия, которые важно понимать на начальном этапе, — компиляция и интерпретация.

### 2.2. Компилируемые языки

**Компиляция** — процесс преобразования исходного кода в другую форму, обычно в машинный код, который может непосредственно выполняться процессором или использоваться при создании исполняемой программы.

Программа, выполняющая такое преобразование, называется **компилятором**.

Упрощённая схема:

```text
Исходный код
     |
     v
Компилятор
     |
     v
Машинный код
     |
     v
Выполнение процессором
```

Например, язык C часто используется с предварительной компиляцией программы в исполняемый файл.

Упрощённый пример:

```c
#include <stdio.h>

int main() {
    printf("Hello!");
    return 0;
}
```

Сначала исходный код обрабатывается компилятором. В результате создаётся исполняемый файл, который затем можно запустить.

**Особенности компиляции:**

- Преобразование исходного кода выполняется до запуска программы.
- Компилятор может обнаружить многие ошибки ещё на этапе сборки.
- Результатом может быть исполняемый файл с машинным кодом.
- Для запуска такого файла обычно не требуется повторно компилировать исходный код.

### 2.3. Интерпретируемые языки

**Интерпретация** — подход к выполнению программы, при котором специальная программа-интерпретатор обрабатывает программный код и организует его выполнение.

В упрощённой модели интерпретатор читает команды и выполняет соответствующие действия.

Схема:

```text
Исходный код
     |
     v
Интерпретатор
     |
     v
Выполнение программы
```

Например, можно запустить Python-файл:

```python
print("Hello!")
```

Интерпретатор Python обработает этот код и выведет текст на экран.

**Особенности интерпретации:**

- Для выполнения программы используется интерпретатор.
- Исходный код можно запускать без самостоятельной подготовки отдельного машинного исполняемого файла.
- Ошибки могут обнаруживаться непосредственно во время выполнения соответствующих участков программы.
- Для запуска программы на другой машине обычно требуется подходящая реализация Python.

### 2.4. Главное различие

| Критерий                       | Компиляция                              | Интерпретация                                |
| ------------------------------ | --------------------------------------- | -------------------------------------------- |
| Основной инструмент            | Компилятор                              | Интерпретатор                                |
| Когда обрабатывается программа | Обычно до запуска                       | В процессе организации выполнения            |
| Результат                      | Часто машинный код или исполняемый файл | Выполнение через интерпретатор               |
| Пример                         | C с традиционной компиляцией            | Python в распространённой реализации CPython |

Это упрощённое сравнение. В современных языках и средах выполнения граница между компиляцией и интерпретацией не всегда строгая.

### 2.5. А Python действительно интерпретируемый язык?

В повседневном общении Python принято называть интерпретируемым языком.

Но технически процесс выполнения Python-программы немного сложнее.

Рассмотрим распространённую реализацию Python — **CPython**.

Когда CPython запускает программу, он обычно выполняет несколько этапов:

1. Получает исходный код Python.
2. Анализирует его структуру и проверяет синтаксис.
3. Преобразует исходный код в промежуточное представление — байт-код Python.
4. Виртуальная машина Python выполняет этот байт-код.

Схема:

```text
Исходный код Python
        |
        v
Анализ и компиляция
        |
        v
Байт-код Python
        |
        v
Виртуальная машина Python
        |
        v
Выполнение программы
```

**Байт-код** — промежуточный набор инструкций, который не является обычным машинным кодом процессора.

Он предназначен для выполнения виртуальной машиной Python.

Таким образом, Python сочетает элементы компиляции и интерпретации.

Это не противоречит тому, что Python традиционно называют интерпретируемым языком. Просто слово «интерпретируемый» описывает общий подход к работе с языком, а не обязательно каждый внутренний этап реализации.

### 2.6. Что нужно запомнить

- Компиляция — предварительное преобразование программы в другую форму, часто в машинный код.
- Компилятор выполняет такое преобразование.
- Интерпретация — выполнение программы с участием интерпретатора.
- Python обычно называют интерпретируемым языком.
- В распространённой реализации CPython исходный код сначала преобразуется в байт-код, который затем выполняется виртуальной машиной Python.

## 3. Что такое Python Interpreter

### 3.1. Определение

**Python Interpreter (интерпретатор Python)** — программная реализация языка Python, которая позволяет обрабатывать и выполнять программы, написанные на Python.

Если программист написал:

```python
print("Hello, Family Budget Bot!")
```

Компьютер не выполняет эту команду напрямую как машинную инструкцию.

Интерпретатор Python обрабатывает написанный код и организует его выполнение.

Именно благодаря интерпретатору компьютер может выполнять программы на Python.

### 3.2. Интерпретатор и язык Python — не одно и то же

Важно различать два понятия:

**Python как язык программирования** определяет правила написания программ:

- какие существуют конструкции;
- как объявляются переменные;
- как работают функции;
- как записываются условия;
- как организованы циклы;
- какие правила синтаксиса необходимо соблюдать.

**Интерпретатор Python** — конкретная программа, которая реализует эти правила и обеспечивает выполнение кода.

Можно провести аналогию:

- язык — это правила и грамматика;
- интерпретатор — программа, которая умеет работать с этим языком.

### 3.3. Что такое CPython

Существует несколько реализаций Python.

Самая распространённая называется **CPython**.

CPython — это основная и наиболее широко используемая реализация Python, написанная преимущественно на языке C.

Когда пользователь скачивает Python с официального сайта для Windows, macOS или Linux, обычно он получает именно CPython.

Другие реализации существуют для различных задач и сред:

- **PyPy** — реализация Python с JIT-компиляцией, которая в некоторых сценариях может ускорять выполнение программ.
- **Jython** — реализация Python для экосистемы Java.
- **IronPython** — реализация Python для платформы .NET.

На начальном этапе разработки нашего Telegram-бота достаточно использовать стандартный CPython.

### 3.4. Что происходит при запуске Python-файла

Допустим, у нас есть файл `main.py`:

```python
print("Hello, Family Budget Bot!")

total = 100 + 200

print(total)
```

Запускаем его командой:

```bash
python main.py
```

В общих чертах происходит следующее:

1. Операционная система запускает программу-интерпретатор Python.
2. Интерпретатор открывает файл `main.py`.
3. CPython анализирует исходный код.
4. Код преобразуется в байт-код.
5. Виртуальная машина Python выполняет инструкции.
6. Программа выводит результаты.

Результат:

```text
Hello, Family Budget Bot!
300
```

### 3.5. Интерактивный режим Python

Интерпретатор можно использовать не только для запуска файлов, но и в интерактивном режиме.

В этом режиме команды вводятся непосредственно в терминале и сразу выполняются.

Например:

```text
>>> 2 + 3
5
>>> print("Hello!")
Hello!
>>> total = 100 + 200
>>> print(total)
300
```

Символы `>>>` — это приглашение интерактивной консоли Python. Они показывают, что интерпретатор ожидает следующую команду.

Интерактивный режим полезен для:

- проверки небольших выражений;
- экспериментов с синтаксисом;
- изучения возможностей Python;
- быстрой проверки отдельных функций;
- поиска причин простых ошибок.

Чтобы выйти из интерактивного режима, можно выполнить:

```python
exit()
```

### 3.6. Интерпретатор и редактор кода

Интерпретатор не является редактором кода.

Например, Visual Studio Code позволяет:

- создавать файлы `.py`;
- редактировать исходный код;
- подсвечивать синтаксис;
- показывать ошибки;
- запускать программы через выбранный интерпретатор.

Но сам по себе редактор не заменяет установленный Python.

Для запуска программы необходимо, чтобы в системе был доступен подходящий интерпретатор.

В нашем проекте мы будем писать код в Visual Studio Code, а выполнять его с помощью установленного Python.

## 4. Как проверить установленную версию Python

### 4.1. Зачем проверять версию

Python развивается: выходят новые версии, добавляются возможности, исправляются ошибки и изменяется поведение некоторых инструментов.

При этом разные проекты могут требовать разные версии Python.

Например, в нашем техническом задании указано требование:

**Python 3.11 или новее.**

Это означает, что для проекта подойдут версии 3.11, 3.12, 3.13 и более новые совместимые версии.

Но версия 3.10 или ниже уже не соответствует этому требованию.

Поэтому перед началом разработки важно убедиться, что установленная версия подходит.

### 4.2. Что такое терминал

**Терминал** — инструмент, через который пользователь взаимодействует с операционной системой посредством текстовых команд.

В Windows можно использовать:

- Windows Terminal;
- PowerShell;
- Command Prompt (cmd);
- Git Bash.

В нашем случае мы работаем в Git Bash.

Через терминал можно запускать программы, работать с файлами, управлять Git и выполнять команды Python.

### 4.3. Проверка версии Python

Основная команда:

```bash
python --version
```

Если Python установлен и команда доступна, терминал покажет примерно такой результат:

```text
Python 3.12.7
```

Здесь:

- `python` — команда запуска интерпретатора;
- `--version` — параметр, который просит вывести версию программы.

Альтернативная команда:

```bash
python -V
```

Она выполняет ту же задачу.

### 4.4. Что делать, если команда python не работает

В разных операционных системах и конфигурациях Python может запускаться под разными именами.

Поэтому можно проверить альтернативные команды.

**Вариант 1:**

```bash
python3 --version
```

Команда `python3` часто используется в Linux и macOS, а также может быть доступна в Windows.

**Вариант 2:**

```bash
py --version
```

`py` — команда Python Launcher для Windows. Она позволяет запускать установленные версии Python.

Например:

```text
Python 3.12.7
```

Если одна команда не работает, это ещё не обязательно означает, что Python не установлен. Возможно, в системе используется другое имя команды или интерпретатор не добавлен в PATH.

### 4.5. Что такое PATH

**PATH** — переменная среды операционной системы, в которой хранится список директорий для поиска исполняемых программ.

Когда пользователь вводит:

```bash
python --version
```

операционная система должна найти программу `python` и запустить её.

Для этого она проверяет директории, перечисленные в PATH.

Если директория с Python отсутствует в PATH, команда `python` может быть недоступна, даже если Python установлен на компьютере.

В таком случае возможны следующие ситуации:

- Python установлен и доступен по команде `python`.
- Python установлен, но доступен по другой команде, например `py`.
- Python установлен, но его директория не добавлена в PATH.
- Python вообще не установлен.

Поэтому важно не делать вывод об отсутствии Python только по одной неудачной команде.

### 4.6. Проверка версии непосредственно из Python

Можно запросить версию из самого интерпретатора.

Сначала запускаем Python:

```bash
python
```

После появления приглашения `>>>` вводим:

```python
import sys

print(sys.version)
```

Модуль `sys` входит в стандартную библиотеку Python и предоставляет информацию о среде выполнения.

`sys.version` содержит информацию о версии интерпретатора.

Пример результата:

```text
3.12.7 (main, ...)
```

Можно получить версию в более удобном для программной проверки виде:

```python
import sys

print(sys.version_info)
```

Результат будет примерно таким:

```text
sys.version_info(major=3, minor=12, micro=7, ...)
```

Здесь:

- `major` — основная версия;
- `minor` — дополнительная версия;
- `micro` — исправительная версия.

Для примера `3.12.7`:

| Часть | Значение |
| ----- | -------: |
| major |        3 |
| minor |       12 |
| micro |        7 |

| Python 3.14 | Да, если используемые зависимости её поддерживают |

Последняя оговорка важна: наличие новой версии Python не гарантирует автоматическую совместимость абсолютно всех сторонних библиотек.

Для учебного проекта лучше использовать стабильную версию, которая поддерживается необходимыми зависимостями.

## 5. Общая схема взаимодействия инструментов

Теперь объединим все понятия.

В нашем проекте будут участвовать три основных элемента:

1. **Python** — язык, на котором мы пишем программу.
2. **Python Interpreter** — программа, которая обеспечивает выполнение нашего кода.
3. **Visual Studio Code** — редактор, в котором мы будем создавать и изменять файлы программы.

Общая схема:

```text
        Разработчик
             |
             v
      Visual Studio Code
             |
             v
       Исходный код
        на Python
             |
             v
     Python Interpreter
             |
             v
      Выполнение программы
             |
             v
          Результат
```

В дальнейшем к этой схеме добавятся другие инструменты:

- **aiogram** — библиотека для взаимодействия с Telegram Bot API.
- **SQLite** — система управления базой данных.
- **aiosqlite** — библиотека для асинхронной работы с SQLite.
- **pytest** — инструмент для автоматического тестирования.

Но основой всего проекта останется Python.

## 6. Краткие выводы

1. Python — высокоуровневый язык программирования общего назначения.
2. Язык программирования позволяет записывать инструкции, которые компьютер может выполнить с помощью соответствующего программного механизма.
3. Высокоуровневый язык скрывает многие низкоуровневые детали работы компьютера.
4. Компиляция — преобразование исходного кода в другую форму, часто в машинный код.
5. Интерпретация — выполнение программы с участием интерпретатора.
6. Python традиционно называют интерпретируемым языком, хотя CPython использует промежуточную компиляцию в байт-код.
7. Python Interpreter — программная реализация языка Python, обеспечивающая выполнение программ.
8. CPython — наиболее распространённая реализация Python.
9. Для нашего проекта требуется Python версии 3.11 или новее.
10. Проверить версию можно командами `python --version`, `python3 --version` или `py --version`.
11. PATH — переменная среды, содержащая пути к директориям, в которых операционная система ищет исполняемые программы.
12. Visual Studio Code — редактор кода, а не замена интерпретатору Python.
